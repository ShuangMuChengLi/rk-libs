## 查找nginx进程
ps -ef | grep nginx
是一个在Linux系统中常用的命令组合，用于查找nginx进程。这个命令组合的工作原理如下：12
ps -ef：这个命令用于显示当前系统中所有进程的详细信息，包括进程ID（PID）、父进程ID（PPID）、CPU占用率、进程运行时间、内存占用情况等。
|：这是一个管道符号，用于将前一个命令的输出作为后一个命令的输入，以实现两个或多个命令的协同工作。
grep nginx：这个命令用于搜索包含特定关键字的文本行。在这个上下文中，它搜索的是包含“nginx”关键字的行，即查找nginx进程的信息。
综上所述，ps -ef | grep nginx 命令组合的作用是列出所有进程的详细信息，并通过grep命令筛选出包含“nginx”关键字的行，从而找到nginx进程的相关信息。
